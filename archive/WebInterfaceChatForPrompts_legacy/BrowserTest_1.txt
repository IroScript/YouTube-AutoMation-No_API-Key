> # browser-use Web Chat Automation Guide

  ## Overview
  This folder contains the `browser-use` framework implementation for controlling Chrome with **Profile 7** via an AI Agent.

  - **Chrome Executable**: `C:\Program Files\Google\Chrome\Application\chrome.exe`
  - **Profile Path**: `C:\Users\Irak\AppData\Local\Google\Chrome\User Data\Profile 7`

  ## Files
  - [`browser_use_chat_test.py`](file:///C:/Users/Irak/Desktop/AntiBotBrowser/WebInterfaceChatForPrompts/browser-use/browser_use_chat_test.py):
  Python script using `browser-use` library.
  - `output.txt`: Output response generated by the agent.

  ## Dependencies
  Install required packages:
  ```powershell
  pip install browser-use langchain-openai
  ```

  ## How to Run

  Set your API Key (e.g. OpenAI or OpenRouter):
  ```powershell
  $env:OPENAI_API_KEY="your-api-key-here"
  ```

  Run the browser-use agent script:
  ```powershell
  python browser-use/browser_use_chat_test.py --url "https://chatgpt.com" --prompt "Write a short poem about AI"
  ```

  ## Features
  - Controls native Google Chrome browser with existing user profile (`Profile 7`).
  - Uses LLM vision & DOM reasoning via `browser-use` agent to perform human-like navigation.
