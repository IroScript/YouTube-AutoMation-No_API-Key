  🧐 CloakBrowser — limitations ও এত ঘাঁটাঘাঁটি কেন?

  তোমার প্রশ্নটা খুব ভালো। এই project anti-bot bypass-এর জন্য বানানো, generic automation-এর জন্য না। তাই design-এর মধ্যেই কিছু fundamental
  trade-off আছে:

  🏗️ CloakBrowser আসলে কী?

  CloakBrowser (github.com/CloakBrowser/CloakBrowser) হলো একটা stealth browser engine — মূল কাজ হলো
  Cloudflare/DataDome/Google-এর bot-detection এড়ানো। মানে এটা Playwright/Puppeteer-এর উপরে বসে fingerprint spoof করে।

  ⚠️ ৫টা মূল সীমাবদ্ধতা — কেন এত ম্যানুয়াল কাজ:

  1️⃣ CloakBrowser reactive, proactive না

  - ❌ আগে থেকে জানে না Google Flow-এর DOM কী
  - ✅ প্রতিটা run-এ fresh DOM scan করে
  - ❌ তাই UI বদলালে প্রতিবার নতুন selector বানাতে হয়

  2️⃣ Cohere/Groq LLM = hallucination prone

  - LLM ভিজ্যুয়াল দেখে selector decide করে — কিন্তু Material icon font name (add_2) আর Bengali text concat করে ফেলে
  - এটা LLM-এর inherent limitation — তাই prompt_templates.py তে constant guard rules add করতে হয়
  - vision model-ও 100% reliable না — আমি যেটা স্ক্রিনশটে দেখলাম সেটা সে ভুল পড়তে পারে

  3️⃣ Anti-bot defense dynamic

  - Google Flow প্রতি সপ্তাহে UI বদলায় (A/B test, feature flag)
  - Bangla/English auto-switch হয় based on browser locale
  - তাই step 1-এর কাজ step 6-এ অন্যরকম হয়ে যায়

  4️⃣ CloakBrowser scope click/type-এই limited

  - ✅ Automation: yes
  - ❌ Self-healing: না (তুমি manually fix করো)
  - ❌ Cross-version compatibility: না (প্রতিটা major UI change-এ re-code)
  - ❌ DOM understanding: shallow (compact JSON dump, no semantic understanding)

  5️⃣ এটা framework, solution না

  CloakBrowser হলো infrastructure layer — তোমার Flow-specific logic আলাদা (google_flow_bot.py, llm_agent.py)। এটা maintain করা
  তোমার দায়িত্ব।

  🤔 বাস্তবতা কী?

  তুমি যা চাও (Google Flow-তে video generate) — সেটা CloakBrowser-এর advertised use-case না। CloakBrowser হলো anti-detect tool,
  কিন্তু তোমার problem হলো complex SPA automation — এটা আলাদা domain।
